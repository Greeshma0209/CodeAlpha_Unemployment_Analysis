# CodeAlpha Unemployment Analysis

## Project Overview
This project analyzes unemployment trends in India using Python. It explores changes in unemployment rates over time, differences across regions, and rural versus urban unemployment.

## Objectives
- Analyze unemployment trends over time.
- Identify regions with higher and lower average unemployment rates.
- Compare rural and urban unemployment.
- Visualize patterns using charts and a correlation heatmap.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
The project uses the **Unemployment in India** dataset.

After data cleaning, the dataset contained 740 records, with duplicate rows and fully empty rows removed.

## Key Findings
- Highest monthly average unemployment rate: May 2020 — 24.88%.
- Lowest monthly average unemployment rate: May 2019 — 8.87%.
- Highest average among regions: Tripura — 28.35%.
- Lowest average among regions: Meghalaya — 4.80%.
- Average rural unemployment rate: 10.32%.
- Average urban unemployment rate: 13.17%.

## Project Workflow
1. Load the dataset.
2. Clean missing and duplicate records.
3. Convert date values and prepare data for analysis.
4. Analyze monthly unemployment trends.
5. Compare regional unemployment rates.
6. Compare rural and urban unemployment.
7. Visualize results using charts and a heatmap.

## Conclusion
The analysis highlights changes in unemployment rates in India during the period covered by the dataset. It identifies differences across regions and between rural and urban areas.
